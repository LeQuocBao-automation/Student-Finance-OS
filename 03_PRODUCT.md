# Student Finance OS — Product

## Product name
Student Money OS / Student Finance OS

## Core promise
Help students build a practical money-management system that starts with saving and adapts to real student life.

## Core framework
Income -> Save First -> Must Keep -> Flexible Spending -> Goals -> Review

## Design philosophy
- simple
- student-friendly
- practical
- adaptive
- behavior-oriented
- not restrictive
- not “you can only spend X VND per day”

## V1
Current direction:
- Google Sheets as main workbook/system
- Google Forms for input/checkup
- Apps Script for useful automation

## Free entry product
Student Money Checkup.

## Paid product
Student Money OS.
Initial price hypothesis: 49k–99k VND.

## Future evolution
Possible later evolution:
- improved automation
- better UX
- web landing page
- web application
- authentication/login
- personal dashboard
- persistent data
- payment integration

Do not build the full SaaS/web app until user demand and product requirements justify it.

## Product improvement loop
User uses product -> friction/feedback -> classify -> prioritize -> implement -> test -> release -> observe again.

Feedback categories:
- bug
- UX issue
- missing feature
- unclear instruction/content
- positioning/business issue
