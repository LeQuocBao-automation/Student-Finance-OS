# Student Finance OS — Claude Context Pack

This folder is the initial project context for giving Claude a structured understanding of Student Finance OS.

## Files
- `CLAUDE.md` — instructions for Claude when working on this project.
- `docs/01_BUSINESS_CONTEXT.md` — what the business is and who it serves.
- `docs/02_STRATEGY.md` — current business/marketing direction.
- `docs/03_PRODUCT.md` — product concept and current/future scope.
- `docs/04_MARKETING.md` — brand voice and content system.
- `docs/05_TECH_ROADMAP.md` — technology and automation direction.
- `docs/06_DECISIONS.md` — current decisions and open questions.

## How to use
1. Create a GitHub repository for Student Finance OS.
2. Upload this entire folder structure.
3. Later, add the chosen open-source code/repository as the implementation base or dependency, depending on its architecture/license.
4. Give Claude access to the repository/project and tell it to read `CLAUDE.md` and the relevant `/docs` files before making changes.

This is a living context pack. Update the documents when important business decisions change.
